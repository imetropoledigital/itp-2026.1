# ITP — Introdução a Técnicas de Programação

Repositório de códigos desenvolvidos durante os encontros síncronos da disciplina **Introdução a Técnicas de Programação** — período **2026.1**, [IMD/UFRN](https://www.imd.ufrn.br).

## Organização

Cada diretório corresponde a uma aula:

| Diretório | Conteúdo |
|-----------|----------|
| `aula01/` | Hello World — primeiro programa em C |
| `aula02/` | Cálculo de aposentadoria |
| `aula03/` | Estruturas de repetição (`while`, `for`) — somatória e Fibonacci |
| `aula04/` | Funções — resolução de problema URI 1541 |
| `aula05/` | Memória e arrays — vetores de velocidades |
| `aula06/` | Matrizes — operações de soma e multiplicação |
| `aula07/` | Tipos de dados |

## Tecnologia

- Linguagem: **C**
- Compilador: **GCC**

## Como compilar

```bash
gcc arquivo.c -o arquivo
./arquivo
```
